# Zo zet je een artikel op de website

(Tekst om als Google Doc "LEESMIJ" in de Drive-map Website te zetten.)

1. Maak in de map **Website** een nieuwe map voor je artikel, bijvoorbeeld
   `Landelijke competitie 5-12-2026`.
2. Zet daarin **precies één Google Doc** met je artikel. Andere bestanden in de map worden
   genegeerd.
3. Begin de Doc met deze regels:

   ```
   Titel: Verslag Landelijke Competitie deel 2
   Auteur: Tom van Daalen
   Datum: 5-12-2026
   ```

   Optioneel: `Categorie: competitie` (kies uit nieuws, competitie, update, aankondiging;
   standaard is nieuws).
4. Schrijf daaronder je artikel. Wat wordt overgenomen:
   - gewone tekst, **vet**, *schuin*, links, opsommingen;
   - kopjes (Kop 1, 2, 3);
   - foto's: plak ze **in de Doc**;
   - video's: zet een YouTube-link **op een eigen regel**, dan wordt het een filmpje.
   Tabellen worden losse regels; kleuren, lettertypes en tekstvakken worden niet overgenomen.
5. Klaar? Zet **website-ready** achter de mapnaam:
   `Landelijke competitie 5-12-2026 website-ready`.

## Wat gebeurt er daarna?

- 's Nachts zet de website het artikel online. Je krijgt een **opmerking in de Doc** met de link.
- Doc nog aangepast? Dan komt de wijziging de nacht erna ook op de website.
- Is de Doc minder dan 30 minuten geleden aangepast, dan wacht de import tot de volgende keer.
- Klopt er iets niet (bijv. de datum ontbreekt)? Dan staat dat als opmerking in de Doc.
- **Artikel weghalen:** haal "website-ready" uit de mapnaam. Het verdwijnt bij de volgende run.
